# BodhAI - Learn Reason Act : Exploring Generative AI, Large Language Models (LLMs), RAG, AI Agents, and Agentic AI
BodhAI is a hands-on learning and experimentation repository dedicated to exploring Generative AI, Large Language Models (LLMs), RAG, AI Agents, and Agentic AI

The name BodhAI is inspired by the Sanskrit word “Bodha” (बोध), meaning knowledge, understanding, or awareness, combined with AI — Artificial Intelligence. It represents a journey from understanding the foundations of AI to building intelligent systems that can learn, reason, use tools, and act autonomously.

This repository will evolve alongside my AI learning journey, bringing together concepts, code experiments, mini-projects, and practical implementations — from the fundamentals of GenAI to advanced agentic systems.
